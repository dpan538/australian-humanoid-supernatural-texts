# Data Availability Statement Draft

The code, configuration files, generated aggregate statistics, paper-preparation scripts, and public documentation for this study are intended to be available through the public repository for the Australian Public Text Archive of Supernatural Humanoid Narratives and Encounters. Repository release and Zenodo DOI: `[TO BE FILLED: repository release / Zenodo DOI]`.

Aggregate statistics used in the manuscript are generated from the paper freeze under `data/releases/paper_hss_discovery_not_evidence_20260706/`. Key files include `paper_stats.json`, `paper_counts.csv`, generated table CSVs, figure source CSVs, and paper validation outputs. These files report count families separately, including local frontend export counts, legacy flat-record counts, V2 normalized counts, strict-gate experiment counts, lead-mode counts, mapped public-record counts, source-family concentration counts, blocker counts, and missingness counts.

Redacted sample data are provided as metadata-only review material in `paper_manual_audit_sample.csv`. The sample omits snippets, descriptions, summaries, raw metadata JSON, source-chain JSON, raw text paths, and full URLs. Sensitive-looking rows are excluded from the public sample by default, and human coding columns are blank until manual review is completed.

Restricted or withheld materials are not redistributed. The paper release does not include copied SQLite databases, raw source text, HTML, XML, PDFs, Word files, cookies, credentials, API keys, private notes, secret or sacred material, non-public community-controlled material, or sensitive Indigenous-related source text. Third-party source texts, catalogue records, web pages, images, and map data remain under their original rights and are not re-licensed by the repository.

Copyrighted source text is not redistributed as part of the paper release. Where public metadata or public source records are discussed, the article uses aggregate statistics, provenance categories, redacted metadata, and citation placeholders rather than reproducing source content.

Live website data and paper freeze data are distinct. The paper freeze records a local static data state and generated aggregate outputs. Live public website display counts are marked as not available in current local data unless a separate deployed-site capture is generated and archived. Manuscript counts should therefore be cited from the paper freeze, not inferred from the live website.
